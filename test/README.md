# Experimental results

This directory contains the complete output files generated by the experiments reported in the revised manuscript. The files are organized into the `benchmark` and `tournament` directories and are compressed individually using bzip2.

## Challenging benchmark

The `benchmark` directory contains the results obtained on the 752,113 challenging tile sets described in the manuscript. It includes the head-to-head games played by every pair of strategies, with the two fixed hands exchanged so that each strategy acts once as the first player and once as the second player.

Each output file is stored separately in `.bz2` format.

## Random-deal tournaments

The `tournament` directory contains the results of the round-robin experiments based on unfiltered random deals. Each strategy pairing was evaluated over 1,000 tournament matches. The output files include the random seeds used for the corresponding runs, allowing the randomly generated deals and results to be reproduced.

Each output file is stored separately in `.bz2` format.
